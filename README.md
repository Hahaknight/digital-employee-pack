## 为什么是"技能"而不是"提示词"？

提示词用一次就丢；技能（SKILL.md）是**装进 Agent 里的标准作业程序**：AI 会在正确的时机自动调用它，并按你定下的规则执行（先诊断后动手、不编数字、结论先行）。一次配置，长期复用。
