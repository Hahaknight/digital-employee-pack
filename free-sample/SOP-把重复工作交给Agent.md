# SOP-01：把任何重复工作变成 Agent 一键完成的流程

> 适用场景：你发现自己每周/每天都在重复做某件事（整理数据、写日报、收集资料）。本流程把它固化成 Agent 的一个指令。

## 五步法

### 第 1 步：录一次"人肉过程"

打开 Agent，把它当成新来的实习生，用文字描述你怎么做这件事，越具体越好：

> "我每周五下午要从飞书导出 3 个表格，删掉前两行说明，把'客户名'列统一成全称，然后按部门汇总金额，贴进周报第 3 节。"

**检查标准**：一个真正的新实习生看完你的描述，能不能不做错？不能就补充。

### 第 2 步：让 Agent 跑一遍，你在旁边挑错

不要追求一次完美。让 Agent 做完，逐项对照你的标准，指出所有问题：

> "第 2 步错了，'客户名'统一要以合同系统为准，不是按拼音排序。"

### 第 3 步：把纠正后的完整流程写进 CLAUDE.md

Agent 会把最终版流程沉淀成文档。你只需要确认它写下来了。下次你说"跑周报流程"，它照做。

### 第 4 步：设定触发词

在 CLAUDE.md 的「快捷指令」区加一行：

> 「跑周报流程」→ 按周报流程文档执行，产出直接写入 report/ 目录

### 第 5 步：每周花 2 分钟抽查

抽查产出物的 3 个关键数字。连续 3 周无误后，这个流程可以完全放手。

## 判断哪些事值得固化（优先级公式）

```
值得固化 = 频率高（周更以上） × 规则明确（能写成步骤） × 出错代价可控
```

优先固化：数据整理、报表汇总、格式转换、信息收集、定期通知文案。
暂不适合：需要临场判断的谈判、创意主导的从 0 写作、涉密内容。

## 常见坑

| 坑 | 对策 |
|---|---|
| 描述太抽象，Agent 每次结果都不一样 | 回到第 1 步，把"大概"变成"具体数字和名称" |
| Agent 改坏了原始文件 | 在 CLAUDE.md 工作规则里强制"只另存新文件"（本包默认已配） |
| 流程里有一环必须人做（如审批） | 显式写"到这一步停下来问我"，不要跳过 |
